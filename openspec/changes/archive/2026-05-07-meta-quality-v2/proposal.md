## Why

Teams generated by the current heuristic engine use generic role-based items (Scope Lens, Shell Bell, Focus Sash) and predefined move tables that don't reflect actual competitive usage — resulting in teams rated "bad" by VGC players. The EV (SP) distribution is also invisible in the web frontend, making the output hard to evaluate. Additionally, users want to save and revisit team variants they like.

## What Changes

- **Meta data service**: New `services/meta_service.py` queries MunchStats API for per-pokémon competitive usage data (items, moves, teammates) and caches locally for 24 h.
- **Item selection upgrade**: `_assign_items` in `team_generator.py` prioritizes the most-used item for the specific pokémon from meta data, falling back to current role-based logic.
- **Move selection upgrade**: `select_moves_for_role` in `replica_exporter.py` prefers meta-popular moves (filtered to moves the pokémon actually knows) over static type tables.
- **Teammate boost**: `_heuristic_filter` scores candidates higher when they appear as frequent teammates of the anchor in meta data.
- **EV display**: `MemberOut` in `schemas.py` gains `sp_distribution` and `ev_note` fields; API router populates them; frontend renders a stat grid and short explanation note.
- **Team presets**: Frontend-only feature (localStorage) — save named/tagged variants, view sprites, copy PokePaste.

## Capabilities

### New Capabilities

- `meta-data`: Per-pokémon competitive usage data (items, moves, teammates) sourced from MunchStats API with 24 h local cache; drives item and move selection in team generation.
- `ev-display`: SP distribution and auto-generated EV rationale note exposed through the API and rendered in the frontend as a stat grid.
- `team-presets`: Browser-side team storage (localStorage) with Pokémon sprites, editable names, color tags, and PokePaste export.

### Modified Capabilities

- `role-balance`: Candidate scoring in `_heuristic_filter` gains a meta-teammate affinity bonus, changing which pokémon rank highest as teammates for the anchor.

## Impact

- **New files**: `pokemon_team_builder/services/meta_service.py`, `tests/test_meta_service.py`, `pokemon_team_builder/cache/` directory for hishel HTTP cache
- **Modified files**: `schemas.py`, `api/router.py`, `services/team_generator.py`, `services/replica_exporter.py`, `web/static/index.html`, `web/static/app.js`
- **New dependency**: No new packages — hishel and httpx already in stack
- **Breaking**: None — new fields are additive; existing API consumers unaffected
